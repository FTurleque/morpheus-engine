Team / remote server (M26, opt-in):
  morpheus [layout] api --remote --host HOST --port PORT --tls-keystore FILE --workspace-root PATH [--workspace-root PATH ...] [--auth-file FILE] [--max-concurrent N] [--provider-plugin-dir PATH]
  Remote mode is HTTPS-only and requires MORPHEUS_SERVER_TLS_PASSWORD, at least one active ADMIN identity and at least one server-owned workspace root.
  morpheus [layout] server identity create --principal NAME --role READ|WRITE|ADMIN [--expires-at ISO-8601] [--auth-file FILE]
  morpheus [layout] server identity rotate --principal NAME [--expires-at ISO-8601|never] [--auth-file FILE]
  morpheus [layout] server identity role --principal NAME --role READ|WRITE|ADMIN [--auth-file FILE]
  morpheus [layout] server identity revoke --principal NAME [--auth-file FILE]
  morpheus [layout] server identity list [--auth-file FILE]
  Rotation preserves the current expiry when --expires-at is omitted; --expires-at never makes the credential permanent.
  morpheus [layout] server identity migrate-legacy --expires-at ISO-8601 [--principal NAME] [--dry-run] [--auth-file FILE]
  migrate-legacy gives non-expiring identities an explicit expiry without rotating any token; it refuses to leave no ADMIN active after the deadline.
  morpheus [layout] server backup create [--output-dir PATH]
  morpheus [layout] server backup verify --file PATH
  morpheus [layout] server restore --file PATH --confirm
  Restore is offline-only; stop the remote server first. Tokens are printed once and only SHA-256 hashes are persisted.
