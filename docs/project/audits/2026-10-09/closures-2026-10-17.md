## Ce qui n'est pas fait

- **`AUD-QUA-17` reste partiel.** Le pilote compteur de `morpheus-api`, `morpheus-cli` et `morpheus-mcp` déregistre
  toujours le pilote SQLite du `DriverManager` de la JVM : c'est un état de processus, et ces trois modules restent
  séquentiels. Une correction demande un compte de connexions physiques attribuable à une base, que le code de production
  ne fournit pas aujourd'hui ; ce n'est pas un détail de test.
- **`AUD-PRF-09` n'est pas corrigé, par décision du mainteneur le 17/10/2026** : l'absence de délai sur les écritures
  proxifiées est un risque accepté et documenté (`docs/user/TEAM_REMOTE_SERVER.md`), et un `504` mentirait pour un commit
  peut-être durable. Le change `bound-every-upstream-call-of-the-remote-proxy` reste ouvert, arrêté.
- **`AUD-PRF-04` ne traite pas** les versions d'un pack de policies et les versions d'une vue enregistrée (paginées
  seulement après lecture, côté MCP), ni aucune purge.
- Le gate M19 n'a pas été exécuté par `validate-m19` sur Linux, ni sur Windows par le validateur : les trois mesures
  ci-dessus sont celles de la classe de gate lancée seule.
- Les notes de version de la version suivante n'existent pas : 1.2.1 est publiée et figée. La rupture de forme de
  l'audit des policies (tableau devenu page) est dite dans `docs/user/UPGRADE_1_2_2.md`.
